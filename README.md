# Объезд

Семестровый проект: простая кроссплатформенная ретро-игра.

Жанр — объезд препятствий на трассе, как в играх начала 80-х
(например, Donkey из каталога old-games.ru), но правила свои.

Машина едет по трёхполосной трассе. Нужно уворачиваться от встречных
машин и камней и подбирать канистры с бензином. Скорость постепенно растёт.

## Архитектура

- Ядро написано на C: стековая виртуальная машина (`src/vm.c`).
- Транслятор (`src/forth.c`) переводит текст на простом Forth-подобном
  языке в байт-код ВМ. На этом языке будет написана игровая логика.

## Язык логики

Программа — это набор слов. Слово определяется так:

    : имя ... ;

Числа кладутся на стек, слова снимают аргументы со стека
и кладут результат. Пример:

    \ комментарий до конца строки
    : square ( n -- n*n ) dup * ;
    : main 5 square 1 + ;       ( на стеке будет 26 )

Встроенные слова:

| Слово | Стек | Действие |
|---|---|---|
| `+ - * / mod` | `a b -- c` | арифметика |
| `= < >` | `a b -- f` | сравнение, результат 1 или 0 |
| `and or` | `a b -- c` | побитовые И, ИЛИ |
| `not` | `a -- f` | 1, если a = 0, иначе 0 |
| `dup` | `a -- a a` | копия вершины |
| `drop` | `a --` | убрать вершину |
| `swap` | `a b -- b a` | поменять местами |
| `over` | `a b -- a b a` | копия второго элемента |
| `@` | `addr -- x` | прочитать ячейку памяти |
| `!` | `x addr --` | записать ячейку памяти |

## Сборка

Нужны `gcc` и `make`.

Linux:

    make

Windows (MinGW):

    mingw32-make

## Тесты

Модульные тесты лежат в каталоге `tests`:

- `test_vm.c` — команды ВМ и обработка ошибок;
- `test_forth.c` — транслятор: числа, слова, комментарии, ошибки.

Запуск:

    make test
