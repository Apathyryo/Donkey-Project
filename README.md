# Объезд

Семестровый проект: простая кроссплатформенная ретро-игра.

Жанр — объезд препятствий на трассе, как в играх начала 80-х
(например, Donkey из каталога old-games.ru), но правила свои.

Машина едет по трёхполосной трассе. Нужно уворачиваться от встречных
машин и камней и подбирать канистры с бензином. Скорость постепенно растёт.

## Архитектура

Программа состоит из трёх частей:

1. **Платформа** — всё, что зависит от ОС: вывод экрана, клавиатура,
   пауза между кадрами (`src/platform.h`).
   - `src/plat_unix.c` — Linux: escape-коды терминала и `termios`;
   - `src/plat_win.c` — Windows: консоль, `conio.h`.
2. **Ядро** на C, не зависит от ОС:
   - `src/vm.c` — стековая виртуальная машина;
   - `src/forth.c` — транслятор Forth-подобного языка в байт-код ВМ;
   - `src/core.c` — загружает скрипт, хранит экран 40x22 символа
     и выполняет системные вызовы скрипта (рисование, клавиши, случайные числа).
3. **Игровая логика** — скрипт `scripts/game.fs` на Forth-подобном языке.
   Ядро вызывает его слово `init` один раз при запуске и слово `tick`
   каждый кадр (20 кадров в секунду).

Ячейка ВМ всегда 32 бита (`int32_t`), поэтому логика работает одинаково
на 32- и 64-битных процессорах.

## Язык логики

Программа — это набор слов. Слово определяется так:

    : имя ... ;

Числа кладутся на стек, слова снимают аргументы со стека
и кладут результат. Пример:

    \ комментарий до конца строки
    : square ( n -- n*n ) dup * ;
    : main 5 square 1 + ;       ( на стеке будет 26 )

Встроенные слова:

| Слово | Стек | Действие |
|---|---|---|
| `+ - * / mod` | `a b -- c` | арифметика |
| `= < >` | `a b -- f` | сравнение, результат 1 или 0 |
| `and or` | `a b -- c` | побитовые И, ИЛИ |
| `not` | `a -- f` | 1, если a = 0, иначе 0 |
| `dup` | `a -- a a` | копия вершины |
| `drop` | `a --` | убрать вершину |
| `swap` | `a b -- b a` | поменять местами |
| `over` | `a b -- a b a` | копия второго элемента |
| `@` | `addr -- x` | прочитать ячейку памяти |
| `!` | `x addr --` | записать ячейку памяти |

Остальные конструкции:

| Конструкция | Что делает |
|---|---|
| `variable имя` | объявляет переменную (только вне определений); её имя кладёт на стек адрес |
| `'A'` | код символа |
| `s" текст"` | кладёт адрес и длину строки |
| `усл if ... then` | выполняется, если на стеке не 0 |
| `усл if ... else ... then` | ветвление |
| `begin ... усл until` | повторять, пока на стеке 0 |

Системные слова (их выполняет ядро):

| Слово | Стек | Действие |
|---|---|---|
| `cls` | `--` | очистить экран |
| `put` | `x y ch --` | поставить символ |
| `text` | `x y addr len --` | вывести строку (`s" ..."`) |
| `num` | `x y n --` | вывести число |
| `key` | `-- k` | нажатая клавиша: 1 влево, 2 вправо, 3 вверх, 4 вниз, иначе код символа, 0 — ничего |
| `rnd` | `n -- r` | случайное число от 0 до n-1 |

Пример — факториал и сумма от 1 до 10:

    : fact ( n -- n! ) dup 1 > if dup 1 - fact * then ;

    variable i
    variable s
    : sum10 ( -- 55 )
        0 s ! 1 i !
        begin s @ i @ + s ! i @ 1 + i ! i @ 10 > until
        s @ ;

## Сборка

Нужны `gcc` и `make`.

Linux:

    make

Windows (MinGW):

    mingw32-make

## Запуск

    ./game          # Linux
    game.exe        # Windows

По умолчанию загружается `scripts/game.fs`, другой скрипт можно передать
аргументом: `./game myscript.fs`. Выход — Esc.

## Тесты

Модульные тесты лежат в каталоге `tests`:

- `test_vm.c` — команды ВМ и обработка ошибок;
- `test_forth.c` — транслятор: числа, слова, комментарии, ошибки.

Запуск:

    make test
